# خطوط أحمد النهر

موقع يعمل بالكامل داخل المتصفح لـ **عرض خصائص الخطوط ومجموعات الأساليب (Stylistic Sets) وتعديلها، ثم تنزيل الخط بعد دمج الميزات المفعّلة داخله**.
لا خادم ولا مكتبات خارجية: HTML وCSS وJavaScript فقط، ولا يُرفع أي خط إلى أي جهة.

*A fully client-side tool to inspect OpenType fonts, preview and toggle features / stylistic sets, edit name-table metadata, and download a font with the chosen features baked in.*

## المزايا

- **الخصائص:** الأسماء، الوزن والعرض، المقاييس، عدد الرموز، تغطية الحروف العربية والتشكيل والأرقام، الأنظمة الكتابية، ترخيص التضمين (`fsType`)، ومحاور الخطوط المتغيّرة.
- **المعاينة الحية:** نص قابل للتحرير مع الحجم والاتجاه واللغة (تؤثر في ميزة `locl`)، ومعرض للأحرف.
- **مجموعات الأساليب `ss01–ss20` ومتغيّرات الحروف `cv01–cv99`:** بطاقة لكل مجموعة بمعاينة قبل/بعد وتعديل اسمها (من جدول `name`).
- **كل ميزات GSUB وGPOS:** بأسماء عربية وتصنيف وبحث.
- **تعديل بيانات الخط:** العائلة، النمط، الاسم الكامل، PostScript، المصمم، الترخيص وغيرها.
- **التنزيل:** TTF/OTF أو WOFF، مع فحص للنسخة الناتجة بمقارنتها بالأصل، وكود CSS بديل.

## التشغيل

```bash
npm start            # خادم ساكن على http://localhost:8080 (أو افتح index.html مباشرة)
npm run build        # ينتج dist/index.html: نسخة من ملف واحد مستقل
```

خطّا Aref Ruqaa وIBM Plex Sans Arabic يُحمَّلان من Google Fonts وللصفحة بدائل احتياطية إن تعذّر ذلك.

## النشر على GitHub Pages

1. ارفع المشروع إلى مستودع GitHub على الفرع `main`.
2. من **Settings → Pages** اختر المصدر **GitHub Actions**.
3. يبني `.github/workflows/pages.yml` الملف `dist/index.html` وينشره تلقائياً.

## هيكل المشروع

```
index.html            الصفحة (تربط css/ وjs/)
css/style.css         التصميم (فاتح/داكن، RTL)
js/font-core.js       منطق OpenType: قراءة/كتابة SFNT وWOFF، GSUB/GPOS، name، ZIP
js/app.js             الواجهة والحالة
scripts/build.js      يدمج كل شيء في ملف واحد
tests/                أدوات التحقق من دمج الميزات
```

## كيف يعمل دمج الميزات؟

بعض الميزات (مثل `rclt` و`liga`) تُشغَّل دائماً في المتصفحات والبرامج، بينما تحتاج `ss01` وأخواتها إلى طلب صريح. لذلك:

1. تُقرأ جداول `GSUB`/`GPOS` وتُحدَّد الميزات التي غيّرها المستخدم عن وضعها الافتراضي.
2. لكل نظام كتابي/لغة تُجمع قواعد (lookups) الميزات المفعّلة في **ميزة جديدة** بوسم غير مستخدم في الخط (`rclt` ثم `clig` ثم `rlig`…)، وتُزال الميزات الأصلية من قائمة ذلك النظام. أما الميزات الموقوفة فتُزال من القوائم فقط.
3. يُعاد بناء `ScriptList` و`FeatureList` مرتّبةً بالأوسمة، وتُحدَّث مؤشرات `FeatureVariations`، وتبقى بقية بايتات الجدول (قواعد الاستبدال) كما هي.
4. يُعاد بناء جدول `name` عند تعديل الحقول، وتُحذف `DSIG`، وتُحسب المجاميع الاختبارية (`checkSumAdjustment`).
5. تُحمَّل النسخة الناتجة عبر `FontFace` كفحص أولي (يمرّ عبر مدقق OTS في المتصفح).

## الاختبارات

```bash
# يبني نسخة معدّلة: <الخط> <ميزات مفعّلة> <ميزات موقوفة> <ملف الإخراج>
node tests/bake-test.js path/to/Font.ttf ss01,ss03 liga /tmp/out.ttf

# يقارن الرسم بـ HarfBuzz/Raqm: يجب أن يتطابق الأصل مع الميزات والناتج بلا ميزات
# المتطلبات: pip install pillow fonttools + مكتبة libraqm
python3 tests/compare_render.py path/to/Font.ttf /tmp/out.ttf ss01,ss03 "نص تجريبي" liga
```

## قيود معروفة

- صيغتا **WOFF2** و**TTC** غير مدعومتين.
- قيم محاور الخطوط المتغيّرة للمعاينة فقط ولا تُدمج في الملف.
- لا يُختار رقم البديل في ميزات مثل `salt` (تُطبَّق بالقيمة ١).
- إن تجاوزت إزاحات جداول الخط حدّ ٦٤ كيلوبايت يظهر خطأ واضح بدل ملف تالف.
- في خطوط CFF يبقى اسم PostScript داخل جدول `CFF` دون تعديل.
- في نسخة claude.ai المنشورة يمرّ الحفظ عبر إمكانية `downloads` (وتُسلَّم OTF/WOFF داخل ZIP)؛ خارجها يُنزَّل الملف مباشرة.

## تنبيه الترخيص

تأكد من أن ترخيص الخط الأصلي يسمح بالتعديل وإعادة التوزيع قبل نشر أي نسخة معدّلة. يعرض الموقع قيمة `fsType` ونص الترخيص المضمَّن في الخط.
